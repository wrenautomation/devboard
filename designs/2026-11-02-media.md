# Videos on the canvas (2026-11-02, WA-1005)

## Goal

An mp4 plays on a board. Stored once however many boards use it. Opening a board downloads no video. Poster first; the video streams only while on screen.

## Options

| | How | Dedupe | Board open cost |
|---|---|---|---|
| **A. Content-addressed media store (chosen)** | `projects/.media/<sha256>.mp4`; an `embeddable` element links `/media/<sha>.mp4`; `renderEmbeddable` draws a `<video>` | global, by bytes | none: the element is a link |
| B. Poster image + link | an image element; tap opens the mp4 | as images | poster only; no play on the canvas |
| C. Excalidraw files map | mp4 as a base64 `dataURL` | per board | every video, base64 (+33 %), on every load and every broadcast |
| D. Outside host | YouTube or S3 link | none | low; breaks self-hosted, bytes leave the Mac |

Priorities: no load cost on the iPad > one copy > build cost. Only A meets the first two.

## Store

- `projects/.media/`: inside the boards repo, so the nightly backup pushes it. The dot name keeps it out of the board list.
- `POST /api/media` takes raw bytes. The server hashes the source as it streams in. A known source returns at once (`src/<source sha>` alias).
- New source: ffmpeg to H.264, at most 720 px wide, CRF 26, `+faststart`, bitexact, metadata stripped. Then a hash of the output names the file. Same output = same file.
- Poster: the last frame as `<sha>.jpg` (a film ends on its payoff). Meta: `<sha>.json` (width, height, duration, bytes).
- One transcode at a time (16 GB Mac).
- `GET /media/*`: static, Range on, `Cache-Control: immutable, 1 year`. A name never changes its bytes.

## Canvas

- Element: `type: embeddable`, `link: /media/<sha>.mp4`. The poster path is derived from the link, so no extra field.
- `validateEmbeddable` accepts `/media/<64 hex>.mp4`. `renderEmbeddable` returns `<video muted playsinline loop preload="none" poster>`.
- It plays while on screen and pauses off screen or when the tab hides. On screen is computed from Excalidraw's scroll and zoom (`appState`). An IntersectionObserver never fired inside Excalidraw's transformed layer in iPad Safari, so the iPad showed only posters. Excalidraw mounts an embed only after it first enters the viewport.
- Tapped (active): native controls. Low Power Mode blocks autoplay; the poster stays until a tap.
- The ↗ link icon on a video (`onLinkOpen`) plays it full screen in place, never in a new tab.
- Headless screenshots: each media embed renders as its poster image.

## CLI

`draw video <file.mp4> [x y] [--width 240]` uploads and places one. `appship <app> film --canvas` uses it.
